# آتلیه صدف — پرتفولیوی طراح لوگو و هویت بصری

نسخه‌ی ۶ — «نسخه‌ی پرداختِ نهایی»: شش تغییرِ این دور، همه با تأییدِ
آزمونِ خودکار (۳۶/۳۶) و بازبینیِ بصری. بسته‌ی کاملِ سورس:
**`atelier-sadaf-front-v6.zip`**

## نسخه‌ی ۶ — پرداختِ نهایی (v6)

### ۱) پیش‌بارگذاریِ دوثانیه‌ای — همیشه، و بی‌درز
- پیش‌بارگذار حالا در هر بازدید اجرا می‌شود (حذفِ کلیدِ جلسه‌ای که
  بارِ دوم را بی‌حس می‌کرد): شمارنده‌ی برنجی تا ۱۰۰، امضای نستعلیق،
  و پرده‌های کاغذی — مجموعاً حدودِ دو ثانیه.
- لحظه‌ی «باز شدنِ پرده» به ورودِ هیرو زنجیر شد: تیترِ «آتلیه صدف»
  زیرِ پرده‌ی در حالِ بالارفتن ظاهر می‌شود — یک نفسِ پیوسته، نه یک
  برشِ خشک. اسکرول کمی پیش از پایانِ پرده به بازدیدکننده برمی‌گردد.

### ۲) رفعِ باگِ «اسکرول پایین و برگشت — متن‌ها ناپدید شدند»
- علت: توییین‌های اسکرولیِ هیرو با `.to()` ساخته می‌شدند و GSAP
  مقدارهای شروع را «تنبلانه» از DOM ضبط می‌کند؛ اگر refresh (فونت/
  بارگذاری) میانه‌ی انیمیشنِ ورود می‌افتاد، مقدارهای نیمه‌انیمیت
  (تیتر در yPercent:115، متن‌ها در opacity:0) به‌عنوانِ «حالتِ صفرِ
  اسکرول» ثبت می‌شدند — برگشت به بالا دقیقاً همان حالتِ خراب را
  برمی‌گرداند.
- راه‌حل: پارالاکسِ اسکرول با `fromTo` با مقادیرِ صریح (غیرقابلِ
  مسموم شدن) و «مسلح‌شدن» فقط پس از پایانِ ورود — یا نخستین حرکتِ
  اسکرولِ بازدیدکننده. آزمونِ A (اسکرولِ عادی) و B (اسکرولِ
  میانه‌ی ورود) هر دو سبز شدند.

### ۳) حال‌وهوا — سریع‌تر و خواناتر
- باندِ اسکرولِ گالری از ۸۵ به ۵۲ واحدِ ارتفاع در هر فریم رسید
  (مجموع: از ~۷ به ~۴٫۶ برابرِ صفحه) و نرمیِ scrub از ۰٫۸ به ۰٫۵۵ —
  همان ریتمِ موزه، با سرعتِ خواندن.

### ۴) نورث‌پیک — برجستگیِ درستِ نشان
- کالبدشناسیِ نشان: خطوطِ سبزِ جنگلیِ تیره. زیرِ ماتِ روشنِ سابق
  با آلپِ مه‌آلود گم می‌شد.
- حالا: لکه‌ی «برف» — ماتِ روشنِ تقریباً-ماتِ پهن‌تر (۷۸٪×۶۴٪) که
  نشان را از هر دو دنیای تیره (کاج‌ها) و روشن (مه) جدا می‌کند؛
  به‌علاوه‌ی سایه‌ی نرمِ drop-shadow برای جداییِ فیزیکیِ لبه‌ها.
  هور و سُها هم سایه‌ی لبه گرفتند.

### ۵) مجموعه — «کارگاهِ نشان» (بازطراحیِ معنادار)
پژوهش درباره‌ی نحوه‌ی نمایشِ «فرآیند» و «نسخه‌های نشان» در پرتفولیوهای
حرفه‌ای (NN/g، Semplice، الگوهای برگه‌ی برند) این‌ها را می‌گویند:
فرآیند را نشان بده نه فقط نتیجه را؛ گریدِ ساخت نشانِ «کارِ طراح» است؛
نسخه‌ی سفید باید روی زمینه‌ی تیره بنشیند. نتیجه:

- **ریلِ فرآیند** بالای صحنه: ۱. گفت‌وگو ← ۲. هندسه ← ۳. رنگ ←
  ۴. نسخه‌ها — گامِ فعال با اسکرول روشن می‌شود.
- **گامِ هندسه**: گریدِ ساخت (خط‌کش، دایره‌ها، مربع‌های چرخیده)
  خودش را می‌کشد (stroke-dashoffset) روی نسخه‌ی مدادیِ نشان.
- **گامِ رنگ**: گرید جمع می‌شود، نشانِ رنگی روی استخرِ رنگِ برند
  می‌نشیند، پالت کنارش.
- **گامِ نسخه‌ها**: چرخه‌ی خودکارِ رنگی ← مشکی ← سفید؛ نسخه‌ی سفید
  روی «پلاکِ جوهری» می‌نشیند (پلاکِ تیره با هیرلاینِ برنجی) —
  ارائه‌ی کلاسیکِ reversed logo. برگه‌ی نسخه‌ها: سه کاشیِ همیشه‌مرئی
  (رنگی/مشکی/سفید) — کلیک = انتخاب + توقفِ ۸ ثانیه‌ایِ چرخه.
- نسخه‌های سفیدِ هر چهار برند تازه ساخته شدند (سفیدِ خالص با حفظِ
  آلفا — اسکریپتِ `make_white_variants`).
- باندِ اسکرول از ۵۶۰ به ۳۸۰svh — فشرده‌تر، پُرتر.

### ۶) سفارش — «تئاترِ یک‌پرسشی» (بازسازیِ کامل)
- ۱۳ پرسش، **یکی در هر پرده** — به‌ترتیبی که یک طراحِ لوگو واقعاً
  لازم دارد: نام → زمینه → روح → رنگ‌ها → کاربرد → زمان/بودجه → تماس.
- تایپ‌گرافیِ بزرگِ سوال، Enter = پرسشِ بعد، انتخابِ تک‌گزینه‌ای
  خودکار جلو می‌رود (۴۶۰ms)، چیپ‌های چندگزینه‌ای با «ادامه».
- نوارِ پیشرفتِ هیرلاین + «پرسش ۳ از ۱۳».
- **مرورِ بریف**: جدولِ همه‌ی پاسخ‌ها با «ویرایش» — پرشِ مستقیم به
  همان پرسش؛ بعد ارسال (API همان /api/order با SQLite/Prisma).

## اجرا

```bash
bun install
bun run dev        # توسعه روی :3000
bun run build      # ساختِ پروडاکشن (standalone)
bun run start      # اجرای پروداکشن با bun
```

## ساختار

- `src/components/portfolio/` — هر بخشِ سایت یک مؤلفه‌ی مستقل است
  (BrandStage، MoodReel، Archipelago، Variations، OrderTheater، …)
- `public/work/` — نشان‌ها؛ برای هر برند: `-color/-gradient`،
  `-black/-bw/-dark`، و `-white` (سفیدِ برگردیده برای زمینه‌ی تیره)
- `public/mood/` — مودبوردها
- `scripts/` — ابزارهای ساختِ دارایی و آزمون (e2e_v5.cjs: ۳۶ آزمون)

## کارایی (میراثِ نسخه‌ی ۵)

دانه‌ی کاغذِ از پیش پخته، دروازه‌ی انیمیشنِ IntersectionObserver،
بدونِ backdrop-blur، توییین‌های فقط opacity/transform — و حالا در
کارگاهِ نشان فقط ۳ تصویرِ برندِ جاری در DOM زندگی می‌کنند.
